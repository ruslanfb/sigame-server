# Дизайн в Penpot как код

Скрипты для официального Penpot MCP (`@penpot/mcp`, инструмент `execute_code`): воспроизводят дизайн-систему
и экраны SIGame в подключённом файле Penpot (`http://192.168.10.217:9001`). Значения токенов совпадают с
`web/src/styles/tokens.css` — источник истины один.

Порядок: `01-tokens.js` → `02-helpers.js` (сохраняет хелперы в `storage`) → `03-foundations.js` (страница «Foundations»
должна быть активной) → на одной странице «Screens»: `10-player.js` (мобайл, y=0) → `20-table.js` (ТВ, y=1100) →
`30-host.js` (пульт, y=2400) → `11-player-desktop.js` (десктоп, y=3500). Скрипты идемпотентны: повторный запуск
пересоздаёт борды с тем же префиксом (P/T/H/D).

## Хелперы v2 — flex-раскладка
Ничего не позиционируется руками: каждый составной элемент — борд с flex-layout (`storage.col/row`), а `storage.add(parent,
child, {fill, fillH, abs, z, mt…})` добавляет ребёнка через layout и задаёт его свойства. `storage.plate(w, h, {variant, label…})` —
шестиугольная плашка: flex-борд по центру + абсолютный path-фон + **фиксированный** текстовый бокс с `align/verticalAlign=center`.
Тексты (`storage.text(str, {w, h, lines, …})`) всегда фиксированные боксы: плагин создаёт текст, а Penpot измеряет его
асинхронно, и авто-ширина остаётся 1×1 до измерения — фиксированный бокс рисуется сразу и в нужном месте.
Готовые блоки: `screen` (фон-градиент + колонка), `card` (панель с заголовком), `input`, `field`, `person`, `score`, `bar`
(таймер), `btn`, `table` (сетка тем×цен, `namePlate` для ТВ), `spacer` (+ `{fillH:true}` прижимает низ). Варианты плашек:
default · active · gold · dim · lit · armed · idle · pressed · locked · success · danger.

## Как запускать
Через MCP-сервер `penpot-ws0` из Claude Code или напрямую, минуя `mcp-remote`:
`python3 scripts/penpot-mcp-call.py execute_code design/penpot/02-helpers.js` (локальный `@penpot/mcp` на `localhost:4401`,
плагин должен быть подключён ровно в одной вкладке Penpot). Смена активной страницы — отдельный вызов:
`let p = penpotUtils.getPageByName('Screens'); penpot.openPage(p);` и пауза ~400 мс.

Ограничения: менять можно только активную страницу; панель плагина в Penpot должна оставаться открытой, иначе соединение
с MCP рвётся; две подключённые вкладки → ошибка «Multiple plugin instances». Экспорт PNG через MCP (`export_shape`) на этом
инстансе не работает (нет exporter'а) — проверяйте визуально в Penpot; геометрию можно снять `storage.geom(board)`.

## Важно: сохранение изменений плагина
Изменения через MCP-плагин применяются во вкладке Penpot и оттуда уходят на бэкенд. Если в этой вкладке цепочка сохранения
сломалась (после ошибки плагина, переключений страниц или обрыва сети до сервера), плагин продолжает «видеть» фигуры и
страницы, которых на сервере нет. Признак — в свежей вкладке борды пустые/страниц нет. Рецепт: перезагрузить вкладку Penpot
(F5), заново подключить плагин, **не создавать/переключать страницы через API** без нужды — открыть страницу руками и строить
только на `penpot.currentPage`; после каждого шага проверять сохранение в отдельной вкладке.
