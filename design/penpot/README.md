# Дизайн в Penpot как код

Скрипты для официального Penpot MCP (`@penpot/mcp`, инструмент `execute_code`): воспроизводят дизайн-систему
и экраны SIGame в подключённом файле Penpot (`http://192.168.10.217:9001`). Значения токенов совпадают с
`web/src/styles/tokens.css` — источник истины один.

Порядок: `01-tokens.js` → `02-helpers.js` (сохраняет хелперы в `storage`) → `03-foundations.js` (страница «Foundations») →
на одной странице «Screens»: `10-player.js` (мобайл, y=0) → `11-player-desktop.js` (y=3500) → `20-table.js` (ТВ, y=1100) →
`30-host.js` (пульт, y=2400). Скрипты идемпотентны: повторный запуск пересоздаёт борды с тем же префиксом (P/D/T/H).

Ограничения плагина: менять можно только активную страницу (`penpot.openPage(page)` + пауза ~400 мс, затем отдельный вызов);
панель плагина в Penpot должна оставаться открытой, иначе соединение с MCP рвётся.

Экспорт PNG через MCP (`export_shape`) на этом инстансе не работает (нет exporter'а) — проверяйте визуально в Penpot.
Дети бордов позиционируются относительно борда через `storage.fixBoard` (Plugin API принимает абсолютные координаты).
